# Simulador Carga Bateria Drone
## Descrição do Problema
Estimativa do tempo de voo e capacidade de carga útil baseada na célula de bateria.
## Requisitos
* Calcular massa máxima de carga.
* Estimar tempo de voo em minutos.
## Exemplo de Uso
Entrada: tensão=14.8, maH=11100
Saída: Carga Máx: 3.52 kg | Voo: 28 min
